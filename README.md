# Tela-de-Login Universidade Las Ensinãs
---
## Descrição

Projeto de aplicação web que implementa um sistema de login seguro utilizando Spring Boot e Spring Security. O objetivo é permitir a autenticação de usuários, e garantindo o acesso apropriado às páginas da aplicação.
Tela de login construida em Java (Spring Boot e Thymeleaf)
